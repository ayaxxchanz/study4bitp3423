The exam-ready argument

Software engineering principles remain important as development becomes continuous, cloud-native and increasingly AI-supported. New technologies bring opportunities and new engineering challenges.

1 · Understand

What the technology does and how it works.

2 · Evaluate

When to use it, its benefits and limitations.

3 · Apply

Integration, engineering risks and realistic adoption.

Foundation & evolution

  • Engineering approaches for development, operation, maintenance
  • Traditional: requirements → design → code → test → deploy
  • Modern: continuous requirements, testing, monitoring & feedback

↳ The method changes; responsibility remains.

02Slides 7–10

Four forces of change

  • Technology: AI, cloud, IoT, edge
  • Business: faster delivery, digital transformation
  • Users: mobile-first, personalisation, availability
  • Society: privacy, sustainability, accessibility & trust

↳ Technology → capability → expectation → challenge.

03Slides 11

10 current trends

  • AI-assisted development • DevOps • Cloud-native
  • Microservices • Platform engineering
  • Low-code/no-code • Supply-chain security
  • Data-driven SE • Green SE • Human–AI collaboration

↳ Trends change practices, not only tools.

04Slides 12–14, 19–20

AI + DevOps

  • AI assists code, tests, requirements, review & documentation
  • Engineer shifts to specify → evaluate → verify → orchestrate
  • DevOps: plan → code → build → test → release → deploy → monitor → feedback
  • Agentic AI: goal → plan → tools → actions → evaluate → adapt

↳ AI output still needs verification.

LECTURE 1 · CORE IDEAPrinciples stay. Methods evolve. Evaluate every new technology.↓ 8 recall branches
05Slides 15–16

Cloud-native + low-code

  • Cloud-native: containers, APIs, microservices
  • Also: elasticity, distributed systems, continuous deployment
  • Low-code: visual + drag-and-drop + citizen developers
  • Evaluate security, scale, maintenance, integration, vendor lock-in

↳ Convenience creates trade-offs.

06Slides 17–21

Emerging AI + twins

  • Emerging = capabilities or adoption still developing
  • GenAI contributes across the software lifecycle
  • AI agents can take actions, raising control and trust questions
  • Digital twins use live real-world data to update a virtual model

↳ Ask: who validates and controls?

07Slides 22–24

Edge + quantum

  • Edge: process close to devices for low latency
  • Edge also reduces transfer; adds distributed complexity
  • Quantum: new computation models, not simply a faster PC
  • Potential quantum uses: optimisation, cryptography, simulation, ML

↳ New capability ≠ universal solution.

08Slides 25–30

Six evaluation questions

  • 1 What problem? • 2 How does it work?
  • 3 When useful? • 4 Limitations?
  • 5 New engineering problems?
  • 6 Can we realistically adopt it?

↳ Finish with an evidence-based decision.

Structured Exam Practice

Past-paper style: a short scenario, numbered subquestions and specific mark allocations. Answer point-by-point, not as a long essay.

PART A15 structured questionsThree practice sets of five questions. Each question: 10 marks, split into (a) and (b).
PART B2 extended case studiesEach case: 25 marks with specific (a), (b) and (c) tasks.
How to answer a structured question

Check the command word (state, identify, explain, discuss, justify), the number of items requested and the allocated marks. For 4 marks, aim for two distinct explained points; for 6 marks, explain three. For a case study, use the facts in the scenario. The suggested full answers, marking points and mark allocations are practice aids, not official answer schemes.
